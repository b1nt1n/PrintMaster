# Известные ограничения

[English](LIMITATIONS.md) · [Руководство](GUIDE.ru.md)

- Только Windows x64. Интерфейс сейчас русский; две версии README не означают переключение языка самой программы.
- Разработка и бумажные тесты проводились с HP LaserJet P1102. Для других драйверов нужно отдельно проверить нестандартную бумагу, аппаратные поля и ручной переворот. Предпросмотр не проверяет физическое положение листа.
- DOCX конвертируется LibreOffice. Подстановка шрифтов и сложные элементы Word могут изменить вёрстку. Office Interop не используется.
- PDF/DOCX представлены страницами для печати; их внутренний текст не редактируется как в Word. Добавленные объекты листа остаются редактируемыми в проекте.
- Markdown не является браузером. Поддержаны HTML-теги `sub`, `sup`, `kbd`, `details`, `summary` без атрибутов. Пары inline-тегов должны находиться в одном абзаце. Summary используется внутри details. Details печатается раскрытым. Остальной HTML остаётся текстом с предупреждением; скрипты и CSS не выполняются.
- LaTeX ограничен возможностями XamlMath и адаптеров PrintMaster. Произвольные пакеты TeX не загружаются. Поддержаны стандартные окружения матриц и `cases`. Историческая прямая команда `\pmatrix{…}` сохраняет поведение upstream; для круглых скобок используй `\begin{pmatrix}…\end{pmatrix}`.
- Формулы оформляются, а не решаются. Ошибка блокирует применение документа и сохраняет исходник.
- Код — моноширинный с фоном, без подсветки синтаксиса.
- Для сносок оставляется одинаковый нижний резерв на страницах. Определения появляются в страницах/колонках со ссылками; повторные ссылки в одной странице/колонке объединяются. Слишком длинная сноска вызывает ошибку. Ссылки на сноски внутри определений не поддерживаются.
- Широкой таблице или формуле может понадобиться меньший шрифт, альбомный лист или больше доступной ширины. Превью облегчённое; детали печати проверяй в экспорте при полном масштабе.
- Тетрадная разлиновка — непечатаемые направляющие. Совпадение со строками зависит от измерений, поправок драйвера и подачи бумаги. При переполнении новый разворот автоматически не создаётся.
- PDF-экспорт растровый, без поискового текста и исходной векторной структуры документа.
- Формат проекта 10 читает 1–10. Старый Markdown требует просмотра и повторного применения перед выводом. Новые проекты открывай новой программой; перед сменой версии сделай копию важных проектов.
- Восстановление недавней работы не заменяет сохранение проекта и резервные копии.
